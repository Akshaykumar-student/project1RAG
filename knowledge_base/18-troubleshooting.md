# General troubleshooting

If FlowDesk does not load correctly, check status.flowdesk.example, refresh the page, and try a private browser window. Supported browsers are the latest two versions of Chrome, Edge, Firefox, and Safari. Disable browser extensions temporarily if the problem occurs only in one browser.

For delayed email, confirm the inbox is active under Settings, check the provider's forwarding or OAuth connection, and send a test message from an unrelated address. If the delay exceeds ten minutes, include the inbox address, approximate send time, and message ID when contacting support.
