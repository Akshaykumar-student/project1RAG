# Create and protect API keys

Admins and owners can create API keys under **Settings → Developers → API keys**. A key is displayed only once. Give each integration its own descriptive key and store it in a secret manager, never in browser code or a public repository.

API keys inherit the permissions selected at creation. Revoking a key takes effect immediately. FlowDesk cannot recover a lost key; create a replacement and revoke the old key.
