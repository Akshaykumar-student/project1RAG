# Automation rules

Growth and Business plans can create rules under **Settings → Automations**. A rule contains one or more conditions and actions. Conditions can inspect inbox, sender, subject, tags, priority, or message text. Actions can assign a teammate, add tags, change priority, or send a saved reply.

Rules run from top to bottom when a new conversation or reply arrives. A conversation stops processing after the first matching rule unless **Continue to next rule** is enabled. FlowDesk records each execution in the conversation activity log.
