# Getting started with FlowDesk

FlowDesk is a shared workspace for managing customer requests. After creating an account, name your workspace, choose its default time zone, and select a support email address. The workspace owner can change these values later under **Settings → Workspace**.

The onboarding checklist asks you to create your first inbox, invite a teammate, connect an email channel, and send a test reply. Completing the checklist is optional and does not affect billing.
