# Connect FlowDesk to Slack

Admins can install the FlowDesk Slack app from **Settings → Integrations → Slack**. Choose one Slack workspace and a default channel. FlowDesk can post notifications for new conversations, assignments, mentions, and priority changes.

Replies written in Slack are not sent to customers. Open the conversation link and reply from FlowDesk. To change the connected Slack workspace, disconnect the integration first and then run installation again.
